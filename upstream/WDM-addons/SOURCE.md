# WDM-addons Reference

WDM-addons is an upstream companion project associated with WDM-patch.

Upstream project:

https://github.com/Trimitor/WDM-Addons

This project is retained as a provenance/reference pointer only during the
initial mod-native-instance-maps work.

The Stable Classic and Burning Crusade instance-map import does not currently
consume files from WDM-addons.

The WDM optional Caverns and Mines functionality may require addon-side
components and is intentionally outside the initial import scope.

No WDM-addons files are currently vendored into this directory.
