## Attribution

This project does not claim authorship or ownership of the original WDM map
artwork or source data.

The upstream files are retained as third-party source/reference material so
that the transformation performed by mod-native-instance-maps is reproducible
and auditable.

mod-native-instance-maps provides tooling, manifests, packaging, validation,
and integration with mod-content-manager. The original map data and artwork
remain attributable to the WDM-patch project and its contributors.

See the upstream project for its original documentation, history, releases,
and applicable usage terms.
