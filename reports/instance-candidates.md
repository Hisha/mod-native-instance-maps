## Classification

**SAFE** — WDM supplies every row the map needs, every one of them is additive against the stock baseline, all references resolve inside the package, and the artwork directory the client derives from `internalName` exists. Publishable now.

**REVIEW** — WDM's rows are additive and internally consistent, but they do not add up to a shippable package. Typically a required `WorldMapTransforms` row is absent, or a `dungeonMapId` reference cannot be satisfied. Closing the gap means authoring rows outside WDM's fixed ID space, so a human decides, not the tool.

**UNSAFE** — building this package would contradict WDM's own data: it depends on a stock row that WDM mutates or drops, or it would hand the client artwork it cannot read. Not publishable under any authoring.
